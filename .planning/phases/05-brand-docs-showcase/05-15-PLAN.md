## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner to third-party actions | five first-party actions execute with the workflow token |
| workflow token to repository and Pages | the token can publish a site |
| published artifact to the public internet | everything under site/dist and docs/api becomes public |
| local git remote to GitHub | the remote decides where a push goes |

| T-05-19 | Elevation | .github/workflows/pages.yml token scope and action integrity | high | mitigate | Every action is pinned by full commit SHA (re-verified with git ls-remote on the planning date; the verify gate fails on any reference without a 40-hex SHA); top-level permissions are contents read and only the deploy job gets pages write and id-token write; no pull request trigger so no fork-controlled code or secrets exposure; persist-credentials false on checkout; concurrency without cancellation so an in-flight deploy is not killed; job timeouts bound runtime; the workflow runs no scripts from untrusted input. |
