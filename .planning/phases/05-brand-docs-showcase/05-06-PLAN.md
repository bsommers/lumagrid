Output: generator, validator, manifest, committed icon files in `site/public/`.

Executor model hint: sonnet. Runs in parallel with plans 05-07 and 05-08: use the targeted commands; the orchestrator runs `bash scripts/ci.sh` after the wave.

Per D-09:
1. brand/assets.json: a declarative manifest with three sections. `pngs`: entries with `src` (an SVG path), `out`, `width`, `height` and `background` (null for transparent, or a hex color). `ico`: the output path and the list of PNG outputs (16 and 32 px) it packs. `copies`: entries with `src` and `out` (favicon.svg copied to site/public/favicon.svg). Start with the favicon-16, favicon-32, the ico and the svg copy; document the schema in a header comment of build-brand.mjs (JSON has no comments).
2. scripts/build-brand.mjs (ESM, chdir to the repo root): read the manifest, refuse any `out` whose resolved path is not inside site/public/ or docs/assets/ (path allow-list), launch the browser once through `launchBrowser` from scripts/lib/browser.mjs, and for each PNG open a page with viewport equal to the target size and device scale factor 1, abort every network request with a route handler, set the content to a margin-free body holding the SVG source inlined at width and height equal to the target (background from the manifest), and capture `page.screenshot` as PNG with `omitBackground` true when the background is null and animations disabled. Write the ICO with a small dependency-free writer: ICONDIR (reserved 0, type 1, count), one 16-byte directory entry per image (width and height bytes with 0 meaning 256, planes 1, 32 bpp, byte length, offset) followed by the raw PNG bytes. Copy files for `copies`. Print one line per output and the browser version. Close the browser in a finally block. Output must be byte-deterministic.
3. scripts/check-brand.mjs: export `checkBrand({ root })` returning an array of error strings and run it from the command line (exit 1 with the list). For every manifest PNG verify the file exists, the PNG signature is present, and the width and height in the IHDR chunk (big-endian at byte offsets 16 and 20) equal the manifest; for the ICO verify the directory count equals the manifest and each entry's size and that the embedded images start with the PNG signature; verify every `copies` output exists.
4. brand/__tests__/icons.test.ts: call `checkBrand` on the repo root and assert it returns no errors (this runs in scripts/ci.sh without a browser because it only reads committed files); also assert the manifest has no output outside site/public/ and docs/assets/.
5. Run `node scripts/build-brand.mjs` and commit the generated files. Run it twice and confirm the generated files are byte-identical.
  </action>
