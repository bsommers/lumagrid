## Start here

Read in this order:

1. [PURPOSE.md](./PURPOSE.md): what Lumagrid is for and the problems it solves.
2. [USING.md](./USING.md): prerequisites, install, entry points, npm scripts and environment variables.
3. [The user guide](./guide/README.md): getting started, transforms, theming, plugins and adapters, and one page per chart.
4. [ARCHITECTURE.md](./ARCHITECTURE.md): the layers, the data flow and the plugin contract.
5. [STABILITY.md](./STABILITY.md): what the `@public` and `@experimental` tags promise.
6. [RELEASE-PLAN.md](./RELEASE-PLAN.md): what remains before the first published release.

## Keeping docs in sync

`npm run docs:check` verifies that every embedded snippet matches its source file, that names are current and that images exist and are local. `npm run visuals` regenerates the chart images and `npm run brand` regenerates the brand PNG and ICO files. Generated files are never edited by hand. The workflows are described in [CONTRIBUTING.md](../CONTRIBUTING.md#docs-brand-and-site).
